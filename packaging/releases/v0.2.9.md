# PS4 FFPFSC 0.2.9

> Отдельные файлы локализации интерфейса, полная локализация на упрощённый
> китайский, а также митигации Windows-ошибок распаковки по Unicode-пути и
> проверки сжатого FFPFSC.
>
> Standalone GUI locale files, Simplified Chinese GUI localization, and
> mitigations for Windows extraction-path and compressed-FFPFSC verification
> failures.

## Загрузки / Downloads

- `PS4-FFPFSC-v0.2.9-macos-arm64.zip` — macOS 13+, Apple Silicon.
- `PS4-FFPFSC-v0.2.9-windows-x64.zip` — Windows 10/11 x64.
- Файлы `.sha256` содержат контрольные суммы архивов.
- `.sha256` files contain archive checksums.

## Русская версия

### Добавлено

- Переводы GUI вынесены из Python-кода в отдельные UTF-8 JSON-каталоги
  `en.json`, `ru.json` и `zh_CN.json`. Пользовательские каталоги можно
  обновлять независимо от исходного кода.
- Добавлен перевод элементов интерфейса, диалогов, статусов и списка игр на
  упрощённый китайский язык.
- Технические строки worker, extractor и MkPFS сохраняются в журнале без
  перевода, чтобы диагностика совпадала с CLI и conversion pipeline не менялся.
- При первом запуске последовательно проверяются языки интерфейса системы,
  затем региональная локаль; выбирается первый доступный каталог, иначе
  английский. Сохранённый ручной выбор имеет приоритет.
- Английский README стал основной страницей проекта; русская версия сохранена
  в `README_RU.md` и доступна по заметной ссылке.
- Сборки PyInstaller включают каталог локалей, а release-аудит требует наличия
  всех трёх штатных переводов.

### Исправлено

- Отсутствующий, повреждённый или частичный файл локали больше не мешает
  запуску GUI: недостающие строки безопасно берутся из английского каталога,
  а в крайнем случае отображается сам ключ.
- Выпадающие списки GUI получили единый тёмный фон popup без белых полос
  системного оформления сверху и снизу.
- В Windows временный staging-путь extractor для названий с не-ASCII символами
  использует стабильный `TITLE_ID`, поэтому `Sekiro™: Shadows Die Twice` не
  передаёт `™` extractor в сгенерированном каталоге. Проверенное дерево затем
  атомарно переносится в обычный возобновляемый workspace; итоговое имя
  сохраняет допустимый Unicode, а запрещённое двоеточие нормализуется.
- В Windows сжатая сборка FFPFSC использует эталонный zlib-backend MkPFS для
  митигации сообщённой ошибки проверки PFSC-потока.
- Публичные аргументы командной строки и этапы конвертации не изменены.

### Проверено

- Автоматическая проверка подтверждает одинаковые 168 ключей, плейсхолдеры и
  форматирование во всех трёх штатных каталогах.
- Регрессионный тест подтверждает не зависящий от названия staging-подпуть из
  ASCII-идентификаторов с `TITLE_ID` для Windows-названия
  `Sekiro™: Shadows Die Twice`.
- Регрессионный тест принудительно выполняет Windows zlib-путь, создаёт образ
  по Unicode-пути `STAR WARS™ Battlefront®`, затем проверяет и распаковывает
  синтетический контейнер.
- macOS arm64 и Windows x64 release-аудиты проверяют включение `en.json`,
  `ru.json` и `zh_CN.json` в автономные приложения.

> [!NOTE]
> Выбор staging-подпути без символов из названия игры проверен отдельным
> регрессионным тестом, а Windows zlib-путь — интеграционной сборкой и глубокой
> распаковкой
> синтетического контейнера. Исходный пользовательский PKG размером около
> 40 ГБ в репозиторий не входит и отдельно на нативной Windows в рамках выпуска
> не воспроизводился.

## English version

### Added

- GUI translations have moved out of Python source into standalone UTF-8 JSON
  catalogs: `en.json`, `ru.json`, and `zh_CN.json`. Community catalogs can now
  be maintained independently of the application source.
- Simplified Chinese localization is included for GUI controls, dialogs,
  statuses, and the game inventory.
- Technical worker, extractor, and MkPFS lines remain verbatim in the log so
  diagnostics match the CLI and the conversion pipeline stays unchanged.
- On first launch, the GUI checks ordered system UI languages and then the
  regional locale, selecting the first matching catalog or English when none
  match. A saved manual choice remains authoritative.
- The English README is now the project landing page; the Russian version is
  preserved in `README_RU.md` and linked prominently.
- PyInstaller builds bundle the locale directory, and release audits require
  all three built-in catalogs.

### Fixed

- A missing, malformed, or incomplete locale file no longer prevents GUI
  startup: missing strings safely fall back to English, then to the key itself.
- GUI combo-box popups now use a consistent dark background without white
  native-style strips above and below the item list.
- On Windows, titles containing non-ASCII characters use a stable `TITLE_ID`
  for the extractor's temporary staging path, so
  `Sekiro™: Shadows Die Twice` does not put `™` in its generated directory.
  The verified tree is then moved atomically into the ordinary resumable
  workspace; the published filename preserves legal Unicode and safely
  normalizes the forbidden colon.
- On Windows, compressed FFPFSC builds select the reference MkPFS zlib backend
  to mitigate the reported PFSC stream-verification failure.
- The public command-line arguments and conversion stages remain unchanged.

### Verified

- Automated validation confirms the same 168 keys, placeholders, and format
  specifications across all three built-in catalogs.
- Regression coverage confirms a title-independent staging subpath composed of
  ASCII identifiers and `TITLE_ID` for the Windows title
  `Sekiro™: Shadows Die Twice`.
- Regression coverage forces the Windows zlib path, creates an image at a
  `STAR WARS™ Battlefront®` Unicode host path, then verifies and unpacks the
  synthetic container.
- macOS arm64 and Windows x64 release audits verify that `en.json`, `ru.json`,
  and `zh_CN.json` are present in the self-contained applications.

> [!NOTE]
> The extractor staging subpath without game-title characters has dedicated
> regression coverage; the Windows zlib path is covered by an integration build
> and deep unpack of a
> synthetic container. The user's roughly 40 GB source PKG is not part of this
> repository and was not reproduced separately on a native Windows host for
> this release.
